# Opit Speech to Text 0.1.3

Published on 2026-10-03 (Europe/Istanbul) as stable **Latest**:
[GitHub release](https://github.com/opit80/opit-speech-to-text/releases/tag/v0.1.3).

## First public release

- Windows 10/11 x64 voice dictation using your own Groq, OpenAI or OpenAI-compatible API key.
- Tray controls, configurable shortcuts, setup wizard and English/Turkish interface.
- Local history, correction rules, provider profiles and usage statistics.
- Interactive usage guide, flexible shortcuts and optional number spelling.
- Signed in-app updates that preserve settings, history, rules and API keys.
- MIT-licensed source code.

## Installation

Download `opit-speech-to-text_0.1.3_x64-setup.exe`. Installation is per-user, without an
administrator prompt. WebView2 may need an internet download if it is missing.

The installer has an updater signature but no Windows Authenticode certificate yet.
Windows may show a SmartScreen warning. See the README for installation and privacy details.

Release files: installer, `.sig`, `latest.json` and `SHA256SUMS`.

## Validation and limitations

Windows/Linux CI, UI checks and release helpers passed. The CI installer and signature were
downloaded independently and verified. Unauthenticated production manifest/installer requests
returned HTTP 200; the actual Tauri updater found, downloaded and verified the release and
offered no update for an already-current version. See `docs/PUBLICATION-REPORT.md`.

The installed app was not updated or restarted, by user request. Clean-machine install/uninstall,
real microphone/clipboard, SmartScreen and autostart acceptance remain manual checks.
