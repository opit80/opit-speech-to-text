# Opit Speech to Text 0.2.0

Unreleased draft. No publish date yet.

## Highlights

- **Linux support.** An AppImage (with signed in-app updates) and a deb package for x86_64.
  Dictation shortcuts are registered with the desktop as commands on KDE Plasma and GNOME; other
  X11 desktops use native key grabs, and other Wayland desktops show a command to bind by hand.
  Shortcuts can be picked from ready-made combinations, recorded in the window or typed. API keys
  are kept in the Secret Service, and recording status appears in a native GTK overlay.
  See [Using the app](../guides/using-the-app.md#linux-differences) and
  [Linux shortcuts](../guides/linux-shortcuts.md).
- **Media while recording.** Other apps' audio is lowered (ducked) while you record, on Windows
  and Linux. **Pause** is available as an alternative.
- **AI cleanup (optional).** Cleans fillers, restarts and punctuation after transcription, with
  named cleanup styles and a style shortcut. Saving a working key now turns cleanup on; a failed
  test leaves it off. The Google AI Studio preset uses `gemini-3.5-flash-lite`. See
  [AI cleanup](../guides/ai-cleanup.md).
- **More providers.** ElevenLabs Scribe v2 (now the recommended choice in the setup wizard) and
  Deepgram presets join Groq, OpenAI and custom OpenAI-compatible servers.
- **Files page.** Transcribe audio and video files to text and subtitles. See
  [File transcription](../guides/file-transcription.md).
- **Voice modes.** Ask an AI agent by voice, dictate with translation, and edit selected text by
  voice (Windows only). See [Ask mode](../guides/ask-mode.md) and
  [Voice edit and translation](../reference/voice-modes.md).
- **Offline local transcription** on Windows. See
  [Local transcription](../guides/local-transcription.md).

## Other changes

- Dictations queue while the app is busy, recordings can be paused, and failed dictations are
  retried patiently and can be recovered.
- Live text preview while speaking with streaming providers, speech calibration and detected
  language.
- Selectable paste methods with an optional Enter or Ctrl+Enter after pasting, per-app rules, and a learning
  dictionary that suggests terms from your History corrections.
- The `opit` command-line tool controls the running app. See [the CLI guide](../guides/cli.md).
- Overlay timing, history limits and a theme choice.
- Simplified Settings: everyday controls stay visible; AI cleanup and Advanced start collapsed.
- Built-in rule packs and the in-app Guide page were removed. Your personal rules (`user.yaml`)
  are kept unchanged, and the short-audio silence filter remains.

## Installation

| File | Platform |
|---|---|
| `opit-speech-to-text_0.2.0_x64-setup.exe` | Windows 10/11 x64 installer (per-user, no administrator prompt) |
| `opit-speech-to-text_0.2.0_amd64.AppImage` | Linux x86_64, updates itself |
| `opit-speech-to-text_0.2.0_amd64.deb` | Debian/Ubuntu x86_64, updated through the package manager |

Release files also include `.sig` updater signatures for the installer and the AppImage,
`latest.json` and `SHA256SUMS`. Existing 0.1.3 installs update in place and keep settings, history,
rules and API keys.

## Known limits

- **Linux verification.** The owner has used the app on KDE Plasma (Wayland), including shortcut
  installation and the default trigger. GNOME, X11 and other-Wayland paths are implemented but not
  yet desktop-verified. The AppImage, deb and AppImage self-update have not been installed or run
  from a release build. See [Linux status](../development/linux-status.md).
- **Linux feature gaps.** No local models, no hold-to-talk (toggle only), no voice edit of selected
  text, and per-app rules only in X11 sessions. Wayland pasting asks for the RemoteDesktop
  permission on the first paste after each launch.
- **SmartScreen.** The Windows installer has an updater signature but no Authenticode certificate
  yet, so Windows may show a SmartScreen warning.
- **Windows acceptance.** Windows CI and the clean-machine [release checklist](../release/RELEASE-CHECKLIST.md)
  for this version are still pending.
